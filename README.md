# Clair & Converti — site de vente express

Landing page responsive en français, prête à héberger.

## Mise en ligne en 10 minutes

1. Ouvrir `index.html` pour vérifier la page.
2. Remplacer l’adresse `bonjour@clair-converti.fr` dans `index.html` par votre email.
3. Remplacer le lien WhatsApp `https://wa.me/?text=...` par votre numéro au format international.
4. Pour encaisser directement, remplacer le lien `mailto:` de `#payment-link` par votre lien Stripe Payment Link / Lemon Squeezy.
5. Déposer le dossier sur Netlify, Vercel ou GitHub Pages.

## Pour obtenir une première vente aujourd’hui

- Publier le lien avec une phrase simple : « Je prends 3 personnes cette semaine pour transformer leur offre en page de vente claire, livrée en 48h. 149 €. Écrivez-moi “PAGE” et je vous envoie les détails. »
- Envoyer le lien directement à 15 prospects qualifiés plutôt que de compter uniquement sur une publication.
- Remplacer le témoignage par un vrai retour client dès que possible. Ne pas présenter le témoignage actuel comme réel s’il ne l’est pas.

Le site ne garantit pas une vente : il réduit surtout les frictions et donne un parcours clair pour demander et payer.
